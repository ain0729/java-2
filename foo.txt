# 📘 Java 정리 노트

## 1️⃣ 프로그래밍 언어 종류

### ✔ 기계어

* 0과 1의 이진수로 구성된 언어
* CPU가 직접 이해하고 실행

### ✔ 어셈블리어

* 기계어를 사람이 읽기 쉽게 만든 언어
* `ADD`, `SUB`, `MOVE` 같은 니모닉 사용

### ✔ 고급언어

* 사람이 이해하기 쉬운 언어
* ex) Java, C, Python

---

## 2️⃣ 프로그래밍 패러다임

### ✔ 절차 지향 언어

* 실행 순서(절차) 중심
* 데이터와 함수 분리
* 재사용성 ↓, 유지보수 어려움
* ex) C, Pascal, Fortran

---

### ✔ 객체 지향 언어

* 현실 세계 객체를 모델링
* 데이터 + 메소드 함께 구성
* 특징:

  * 상속
  * 캡슐화
  * 다형성
* 장점: 재사용성, 유지보수 ↑

---

### ✔ 함수형 언어

* 함수 중심 프로그래밍
* 상태 변경 최소화, 불변성 유지
* 특징:

  * 재귀
  * 고차 함수
  * 순수 함수
* ex) Python, Kotlin, Haskell, Lisp, Scala

---

## 3️⃣ 컴파일 과정

* **소스 코드**: `.java`
* **바이트코드**: `.class`
* **실행 과정**

  ```
  .java → 컴파일 → .class → JVM 실행
  ```

---

## 4️⃣ Java 특징

### ✔ WORA (Write Once Run Anywhere)

* 한 번 작성하면 어디서든 실행 가능
* 플랫폼 독립성

### ✔ JVM

* 자바 실행 환경 제공
* 바이트코드를 해석/실행

---

* int
* long
* float
* double

---

### ✔ 참조형

* 클래스

## 6️⃣ 식별자 규칙

* 숫자로 시작 ❌
* 특수문자 대부분 ❌ (`$`, `_`는 가능)
* 키워드 사용 ❌
* 대소문자 구분
* 길이 제한 없음

---

## 7️⃣ 변수 / 상수

### ✔ 상수

```java
final double PI = 3.141592;
```

* 값 변경 ❌

---

### ✔ var 키워드

* Java 10부터 사용
* 타입 자동 추론
* **초기값 필수**

```java
var num = 10; // int로 자동 결정
```

---

## 8️⃣ 메모리 구조

* **스택(Stack)**: 지역변수 (LIFO)
* **힙(Heap)**: 객체 저장

---

## 9️⃣ 연산자

### ✔ 비교 연산자

* `<`, `>`, `<=`, `>=`, `==`, `!=`

---

### ✔ 논리 연산자

* `&&` (AND)
* `||` (OR)
* `!` (NOT)
* `^` (XOR)

---

### ✔ 조건 연산자 (삼항 연산자)

```java
(a > b) ? a : b;
```

* 조건 ? 참 : 거짓

---

### ✔ 비트 연산

* AND `&`
* OR `|`
* XOR `^`
* NOT `~`

---

### ✔ 비트 시프트

* `<<` (왼쪽 이동)
* `>>` (오른쪽 이동)

---

## 🔟 핵심 개념 정리

* Java는 **컴파일 + 인터프리터 방식**
* 실행 흐름:

  ```
  소스코드 → 바이트코드 → JVM → 실행
  ```
* 플랫폼 독립성 = **JVM 덕분**
